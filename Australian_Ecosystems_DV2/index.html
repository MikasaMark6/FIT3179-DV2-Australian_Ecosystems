01

Read the landscape through vegetation

These charts use official Major Vegetation Groups (MVGs). Forests, woodlands and grasslands describe vegetation; deserts describe dry environments, while wetlands can contain several vegetation types. They are not four separate, exhaustive categories.

Click the map to focus a type. Use the menu for keyboard access. Focus changes emphasis, not percentages.

Other mapped classes

Display: approximately 5 km cells, sampled from the NVIS 100 m raster. Small coastal patches may disappear at this scale. Map cells are not used to calculate areas. Extant data have different observation dates across regions.

02 / AREA COMPARISON

Which Native Vegetation Types Cover the Most Land?

Ranked by mapped extant area. The initial selection shows ten representative groups; switch to all 25 for the complete ranking.

Area describes extent, not species richness or ecological importance. A smaller ecosystem can still matter greatly.

Area statistics use original 100 m NVIS cells in an equal-area projection. One cell equals one hectare. Percentages in tooltips use all 25 classified native groups nationwide as the denominator.

03 / STATE COMPOSITION

Native Vegetation Composition Across States

Which vegetation groups make up each state's classified native vegetation? Darker cells indicate a larger share.

The same national categories reveal different regional landscapes. Hover to see each state's area and percentage.

Each percentage divides the group's area by all 25 classified native groups in that state. It does not measure the percentage of the state's total land. All 25 groups sum to 100% per column; the representative subset does not. Other Territories are omitted.
